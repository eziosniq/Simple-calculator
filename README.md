# Simple-calculator
Этот проект демонстрирует организацию исходного кода с использованием системы контроля версий Git. Он включает базовые функции калькулятора: сложение, вычитание, умножение, деление и возведение в степень.
ФУНКЦИИ
add(a, b) — сложение
subtract(a, b) — вычитание
multiply(a, b) — умножение
divide(a, b) — деление (с проверкой на ноль)
power(a, b) — возведение в степень
ИСТОРИЯ РАЗРАБОТКИ
1. Создана структура проекта и базовые функции (initial commit).
2. Добавлена функция power в ветке develop.
3. Изменения объединены с основной веткой main.
ТРЕБОВАНИЯ
